# Component downloads

Start with [the current component index](../START-HERE.md), [standalone helper ZIP](https://github.com/Mohammed-Moniem/embedded-office-suite/releases/download/v0.1.0-progress.3/office-kit-downloader-progress3-r2.zip) and [transfer instructions](DOWNLOAD-KIT.md). The download-only helper needs an approved Node22+ runtime and GitHub access on the connected machine; it uses native fetch and needs no npm packages, Cargo registry access, token or account. Transfer its matching script/config pair with the archives so it can verify them again offline on the corporate laptop. Its [exact public extraction/offline check](verification/public-download-kit-progress3.json) records the measured scope.

For one target, the runtime profile collects two archives: native workers/Node SDK and the four WASM editors. The build profile collects seven: complete source3 engine baseline, four Cargo vendor archives, support data and matching Rust/build tools. The all profile collects all nine. Every selected file must match its fixed size and SHA-256. The helper never extracts, installs, runs downloaded code or changes the private host.

Actual [run42406484290](https://github.com/Mohammed-Moniem/embedded-office-suite/actions/runs/42406484290) passes all15 helper CLI stages on macOS15 ARM64, Intel Mac and Windows Server2022: full runtime downloads, fetch-forbidden offline verification, read-only plan, wrong-file preservation and offline-missing refusal. See the [measured results](verification/public-download-kit-three-platform.json), [independent review](verification/download-kit-three-platform-review1.json) and [public evidence replay](verification/public-download-kit-three-platform-durable.json). This tests transfer/integrity rather than archive execution or Windows console signals.
