# Official feature comparison

Comparison date: **2026-11-07**. This compares selected major workflows with official Microsoft 365 Word, Excel and PowerPoint documentation, Microsoft's PDF workflows, and Adobe Acrobat documentation. It uses the reviewed dated documentation baseline; no licensed reference application is required or claimed to have been run.

**Status: IN_PROGRESS.** Of 52 selected workflows, **14 are implemented, 23 partial, 5 missing and 10 unverified**. This is a selected workflow inventory, not an exhaustive feature list or a parity percentage. Implemented means a bounded authoring path or recorded operation exists; the practical limit in each row remains part of the claim.

| GridCraft | 3 | 7 | 2 | 1 |

The five missing rows are Word PDF input; Grid Power Query and password-encrypted workbook output; and Deck video output and ODP/legacy binary exchange. Source3 includes the reviewed Deck unsupported-format refusal; the older runtime archives retain their earlier identities. Source3 does not add these missing converters.

**C** = current source inspected; **R** = existing operation receipt inspected; **T** = test source inspected, not rerun by the comparison audit. A source handler or test count alone does not establish arbitrary file preservation, matching layout, printing, assistive-technology behavior or full product equivalence. Windows11 and the private desktop host require their own acceptance.
