# Embedded Office integration components

Status: **IN_PROGRESS**. WordCraft, PdfCraft, DeckCraft and GridCraft are packaged for the existing approved Node/WebView desktop host. The native workers and WASM editors need no Cargo registry access at runtime. The complete source and optional Rust build inputs are separate downloads.

The current standalone CLI/source releases are listed in [Current personal Office components](CURRENT-COMPONENTS.md). This page documents the older Node/WebView SDK and WASM baseline; each package retains its own source and validation scope.

Start with the [standalone download-helper ZIP](https://github.com/Mohammed-Moniem/embedded-office-suite/releases/download/v0.1.0-progress.3/office-kit-downloader-progress3-r2.zip) and [transfer instructions](docs/DOWNLOAD-KIT.md). Helper ZIP SHA-256:483613519eb407b3c13a1c209e324c95cfb5b7cbb785322e6c4e8e0148c23c61. Its runtime profile collects two archives for the target machine; its all profile also collects the complete source3 engine baseline, four vendor archives, support data and matching Rust tools. The helper verifies sizes and SHA-256 values and can verify the transfer again offline. It does not install or extract files. The [public helper check](docs/verification/public-download-kit-progress3.json) verifies the exact extracted tool and offline CLI.

Extract the native and WASM ZIPs into separate directories using the approved OS tools. Verify their `MANIFEST.json` files, then follow [host integration](docs/HOST-INTEGRATION.md) to mount the existing editors, route tool calls and supply storage/permission callbacks. The native package includes `sdk/node/examples/native-smoke.mjs` for a simple create/save check. Configure Grid's filesystem policy as `automation-roots`. Grid's headless PNG rendering is unsupported; visible spreadsheet editing uses the WASM editor.

The exact public native archives were exercised in [run42402906309](https://github.com/Mohammed-Moniem/embedded-office-suite/actions/runs/42402906309), with their own packaged SDKs, an empty executable search path, actual edit/save/reopen and scoped OS network restrictions. The Windows wrapper also verified removal of its five rules and restoration of profile/service state. [Run42402918764](https://github.com/Mohammed-Moniem/embedded-office-suite/actions/runs/42402918764) verified all44 fixed reconstruction data assets through anonymous full downloads.
